# Логотип Device Workshop

`logo.png` — прозрачная версия логотипа, подготовленная из присланного пользователем квадратного изображения: градиентный контур яблока и зелёный Android внутри. Используется в шапке, подвале, блоке мастерской, иллюстрации чата бота и значке страницы.

Дополнительный референс с телефоном, временем работы и адресом перенесён в доступный HTML-блок контактов. Телефон и адрес кликабельны, текст можно увеличить и выделить, а график подтверждён владельцем: ежедневно 10:00–20:00. Это обеспечивает читаемость на телефоне вместо уменьшения всей растровой карточки.
